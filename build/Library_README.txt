This folder is your Face Sorter library (مكتبة الوشوش).

- library.db  = everything the program knows about people (faces, names, history).
- backups\    = automatic copies, made before every saved session.

Keep this folder next to the "FaceSorter" folder (for example both on the USB stick).
You can copy this folder on its own to move or back up the library.
Do not edit library.db by hand.
