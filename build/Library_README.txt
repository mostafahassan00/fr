This folder is your Face Sorter library.                       ده فولدر مكتبة Face Sorter بتاعتك.

FaceSorter_Library_created-<date>_updated-<date>.db
    Everything the program knows about people: names, face prints, small face pictures,
    visits and history. The dates in the name change by themselves.
    كل اللي البرنامج يعرفه عن الناس: الأسامي، وبصمات الوشوش، وصور صغيرة للوشوش، والزيارات والسجل.
    التواريخ اللي في الاسم بتتغير لوحدها.

FaceSorter_Library_....key   (only if the library has a password | بس لو المكتبة عليها باسورد)
    Needed to open the encrypted library. Keep it next to the .db file.
    لازم يفضل جنب ملف الـ .db عشان المكتبة المتشفرة تتفتح.

backups\
    Automatic copies, made before every saved session (encrypted too, if there is a password).
    نسخ احتياطية بتتعمل لوحدها قبل كل جلسة بتتحفظ (ومتشفرة كمان لو فيه باسورد).

Keep this folder next to the "FaceSorter" folder (for example both on the USB stick).
You can copy this folder on its own to move or back up the library. Do not edit the files by hand.
خلي الفولدر ده جنب فولدر "FaceSorter" (مثلاً الاتنين على الفلاشة). تقدر تنسخه لوحده عشان تنقل المكتبة
أو تاخد منها نسخة. متعدّلش الملفات بإيدك.

Your photos are NOT in here: the library keeps faces and names, not photos.
صورك مش هنا: المكتبة فيها الوشوش والأسامي، مش الصور.
